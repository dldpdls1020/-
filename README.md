# 뷰티데이트 랜딩페이지

정적 HTML/CSS/JavaScript로 만든 뷰티데이트 소개 페이지입니다. 디자인 레퍼런스의 모노톤 에디토리얼 분위기를 바탕으로, 눈썹 반영구 포트폴리오와 원장 소개, 샵 공간, 예약 안내를 구성했습니다. 데스크톱·태블릿·모바일 화면에 대응하며, 페이지 진입 애니메이션과 스크롤 리빌, 모바일 메뉴 인터랙션을 포함합니다. 기기의 동작 줄이기 설정을 존중합니다.

## 미리보기

`index.html`을 브라우저에서 열면 페이지를 확인할 수 있습니다.

## 사진

`assets/`에는 데스크탑의 `바이브코딩/조수연 뷰티데이트` 폴더에서 복사한 사진을 사용했습니다.

- `brow-01.jpg` ~ `brow-46.jpg`: 눈썹 결과 사진
- `process-01.jpg` ~ `process-09.jpg`: 시술 장면 및 프로필 사진
- `studio-01.jpg` ~ `studio-10.jpg`: 샵 내부 사진

현재 페이지는 실제 고객 사례와 원장 프로필을 보여줍니다. 배포 전 게시 사진의 사용 동의와 각 결과 이미지의 설명을 확인해 주세요.

## 언어

상단의 언어 선택 메뉴에서 한국어, 일본어, 중국어 번체(대만), 영어로 전환할 수 있습니다. 브라우저에 마지막으로 선택한 언어가 저장됩니다.

## 공개 전에 채워야 할 정보

- 상세 주소와 운영 시간, 휴무일, 주차·대중교통 안내
- 네이버 예약과 카카오톡 채널 링크
- 확정된 시술 가격 및 리터치 정책
- 영업 신고·사업자 등 푸터에 게시할 사업 정보
- 언어별 문의 응대 가능 시간 및 연락 방법

가격 및 예약 정책은 확정 정보가 없어 페이지에 임의로 게시하지 않았습니다.
